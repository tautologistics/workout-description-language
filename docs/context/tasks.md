# Tasks

The project's queue, split by disposition. Everything here is a self-contained
piece of work — roughly in the order it would be taken, each stating what it
touches.

## Current Tasks

Open, in-progress, and soon-actionable — including all closed items' numbering
for continuity. Load this when starting a session with no task named.

-> [tasks/current.md](tasks/current.md)

## Deferred

Real holes, valid but deliberately postponed, and what would make one worth
picking up.

-> [tasks/deferred.md](tasks/deferred.md)

## Completed And Terminal

The queue's closed history — what was decided, what it cost, and the
corrections made along the way. Read before re-proposing something that was
already tried.

-> [tasks/completed.md](tasks/completed.md)

Separately, defects and gaps caught by *driving the builder* rather than by
planned work — unordered, each dispatchable on its own — are in
[topics/builder-ux.md](topics/builder-ux.md).
